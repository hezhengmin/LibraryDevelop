# Feature Specification: 管理後台 UI 樣式統一

**Feature Branch**: `004-admin-ui-styling`  
**Created**: 2026-04-11  
**Status**: Draft  
**Input**: User description: "登入樣式、登入頁面的左側選單等等，裡面的樣式，可以參考 vue3-element-admin 跟他差不多"

## 概述

將現有圖書館管理系統的前端樣式（含登入頁面、主佈局、左側導覽選單、頂部導航欄）全面對齊 vue3-element-admin 的視覺風格。目標是打造專業、一致的後台管理介面體驗，涵蓋深色側邊欄、深色登入背景、固定頂部導覽列、Logo 展示、收合/展開側邊欄動畫等標誌性設計元素。

## 參考風格摘要（vue3-element-admin）

| 區域 | 參考風格特徵 |
|------|-------------|
| 登入頁面 | 全屏深色背景（#2d3a4b）、置中表單卡片、白色文字、暗色輸入框、密碼顯示/隱藏切換 |
| 側邊欄 | 固定左側、深藍黑背景（#304156）、白色/淺灰文字、滑鼠懸停高亮、子選單展開收合、Logo 區塊 |
| 頂部導航欄 | 固定頂部、白色或淺色背景、漢堡按鈕切換側邊欄、麵包屑導覽、右側使用者頭像與下拉選單 |
| 主佈局 | sidebar + main-container 結構、側邊欄收合時寬度縮減為 54px、過渡動畫 0.28s |
| 響應式 | 行動裝置時側邊欄覆蓋式展開、背景遮罩層 |

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 登入頁面視覺升級 (Priority: P1)

使用者造訪登入頁面時，看到深色背景、置中的表單區域、白色/淺色文字的專業後台管理系統風格，與 vue3-element-admin 的登入頁面視覺一致。表單輸入框為暗色風格、密碼欄位有顯示/隱藏切換按鈕，整體呈現企業級管理後台的質感。

**Why this priority**: 登入頁面是使用者進入系統的第一印象，視覺品質直接影響對整體系統的信任感。

**Independent Test**: 開啟瀏覽器造訪登入頁面，目視確認深色背景、置中表單、白色文字等樣式是否與參考風格一致。

**Acceptance Scenarios**:

1. **Given** 使用者未登入，**When** 造訪登入頁面，**Then** 看到深色全屏背景與置中的登入表單
2. **Given** 登入頁面已載入，**When** 使用者檢視表單，**Then** 輸入框為暗色風格、帶有圖示前綴、密碼欄位有顯示/隱藏切換
3. **Given** 登入頁面已載入，**When** 使用者在手機寬度瀏覽器檢視，**Then** 表單自動適應螢幕寬度，維持可讀性
4. **Given** 登入頁面已載入，**When** 使用者同時看到社群登入按鈕與註冊連結，**Then** 視覺風格與表單區域一致、不突兀

---

### User Story 2 - 左側導覽選單樣式升級 (Priority: P1)

已登入的使用者在主佈局中看到左側固定的深色側邊欄，包含系統 Logo、選單項目（帶圖示）、子選單展開收合、滑鼠懸停高亮效果，與 vue3-element-admin 的側邊欄風格一致。

**Why this priority**: 側邊欄是使用者操作系統最頻繁接觸的元素，其可用性與美觀度對日常使用體驗影響最大。

**Independent Test**: 登入後進入主頁面，目視確認側邊欄為深色背景、白色文字、有 Logo 區塊、滑鼠懸停高亮、收合/展開功能正常。

**Acceptance Scenarios**:

1. **Given** 使用者已登入，**When** 進入主介面，**Then** 左側顯示深色固定側邊欄，寬度約 210px
2. **Given** 側邊欄為展開狀態，**When** 使用者點擊收合按鈕，**Then** 側邊欄平滑（0.28s）收合至僅顯示圖示（約 54px 寬）
3. **Given** 側邊欄有子選單，**When** 使用者點擊父選單項，**Then** 子選單平滑展開/收合
4. **Given** 側邊欄已渲染，**When** 使用者將滑鼠懸停在選單項上，**Then** 該選單項背景色高亮顯示
5. **Given** 側邊欄頂部，**When** 使用者檢視，**Then** 看到系統 Logo 與名稱（收合時僅顯示圖示或簡稱）

---

### User Story 3 - 頂部導航欄與主佈局升級 (Priority: P2)

已登入的使用者在主佈局中看到固定的頂部導航欄（白色/淺色背景），包含漢堡按鈕（切換側邊欄收合）、麵包屑導覽以及右側使用者資訊與登出功能，與 vue3-element-admin 的頂部導航欄風格一致。

**Why this priority**: 頂部導航欄提供操作上下文與快捷操作，與側邊欄配合形成完整的後台佈局，但相對於側邊欄其改動量較小。

**Independent Test**: 登入後確認頂部白色導航欄固定在頂部、漢堡按鈕可切換側邊欄、顯示麵包屑與使用者資訊。

**Acceptance Scenarios**:

1. **Given** 使用者已登入，**When** 進入主介面，**Then** 頂部顯示固定白色導航欄，包含漢堡圖示（側邊欄切換）
2. **Given** 頂部導航欄已渲染，**When** 使用者點擊漢堡圖示，**Then** 側邊欄切換收合/展開，主內容區寬度隨之調整
3. **Given** 使用者在某子頁面，**When** 查看頂部導航欄，**Then** 顯示對應的麵包屑路徑
4. **Given** 頂部導航欄右側，**When** 使用者檢視，**Then** 看到使用者頭像、名稱與下拉選單（含登出等操作）

---

### User Story 4 - 行動裝置響應式佈局 (Priority: P3)

使用者在手機或平板等窄螢幕裝置上使用系統時，側邊欄以覆蓋式滑出、搭配半透明背景遮罩，點擊遮罩或選單項後自動收合，不影響主要內容區的操作。

**Why this priority**: 行動裝置使用情境為輔助需求，確保不遮擋主內容即可。

**Independent Test**: 將瀏覽器窗口縮至手機寬度（< 768px），確認側邊欄為覆蓋式展開並帶遮罩。

**Acceptance Scenarios**:

1. **Given** 螢幕寬度 < 768px，**When** 使用者開啟側邊欄，**Then** 側邊欄從左側滑出覆蓋在主內容之上，背後有半透明遮罩
2. **Given** 行動裝置上側邊欄已開啟，**When** 使用者點擊背景遮罩，**Then** 側邊欄自動收合
3. **Given** 行動裝置上側邊欄已開啟，**When** 使用者點擊某選單項導覽，**Then** 側邊欄自動收合，頁面切換至對應路由

---

### Edge Cases

- 側邊欄收合狀態下，有深層子選單的項目改以彈出式（popup）方式顯示
- 視窗尺寸在桌面與行動裝置臨界值（768px）附近反覆切換時，佈局切換應流暢無卡頓
- 選單項文字過長時，需截斷並以 tooltip 顯示完整文字
- 登入頁面在超高或超寬螢幕下，表單仍維持合理尺寸並水平垂直置中
- 深色模式下（若未來支援），登入頁與側邊欄配色應有對應方案

## Requirements *(mandatory)*

### Functional Requirements

#### 登入頁面

- **FR-001**: 登入頁面 MUST 呈現全屏深色背景，表單區域水平垂直置中
- **FR-002**: 登入表單輸入框 MUST 為暗色/半透明風格，帶有圖示前綴（使用者圖示、鎖頭圖示）
- **FR-003**: 密碼欄位 MUST 提供顯示/隱藏密碼切換按鈕
- **FR-004**: 登入頁面上的所有文字 MUST 為白色或淺灰色，確保在深色背景上的可讀性
- **FR-005**: 登入頁面 MUST 保留現有的社群登入按鈕與註冊連結，且樣式與深色背景風格一致
- **FR-006**: 登入頁面 MUST 在行動裝置上（< 640px）自動調整表單寬度

#### 側邊欄

- **FR-007**: 側邊欄 MUST 為深色背景（深藍黑色調），固定定位於頁面左側，佔滿整個視窗高度
- **FR-008**: 側邊欄頂部 MUST 顯示系統 Logo 與名稱（展開時）或僅 Logo 圖示（收合時）
- **FR-009**: 側邊欄 MUST 支援展開（約 210px）與收合（約 54px）兩種狀態，並有平滑過渡動畫
- **FR-010**: 選單項 MUST 顯示對應圖示與文字，收合狀態下僅顯示圖示
- **FR-011**: 滑鼠懸停選單項時 MUST 變更背景色以提供視覺回饋
- **FR-012**: 目前所在頁面對應的選單項 MUST 以高亮色標示（active 狀態）
- **FR-013**: 有子選單的項目 MUST 支援展開/收合子選單，並帶有展開方向指示箭頭
- **FR-014**: 側邊欄內容超出視窗高度時 MUST 顯示滾動條

#### 頂部導航欄

- **FR-015**: 頂部導航欄 MUST 固定在頁面頂部，白色或淺色背景，不隨內容滾動
- **FR-016**: 頂部導航欄左側 MUST 顯示漢堡按鈕，點擊可切換側邊欄收合/展開狀態
- **FR-017**: 頂部導航欄 MUST 顯示麵包屑導覽，反映當前頁面的路由層級
- **FR-018**: 頂部導航欄右側 MUST 顯示使用者頭像與名稱，並附帶下拉選單（含登出等功能）

#### 主佈局

- **FR-019**: 主內容區域 MUST 隨側邊欄收合/展開自動調整左邊距，並有平滑過渡動畫
- **FR-020**: 行動裝置上（< 768px），側邊欄 MUST 改為覆蓋式展開，並附帶半透明背景遮罩
- **FR-021**: 點擊行動裝置上的背景遮罩 MUST 收合側邊欄

### Non-Functional Requirements (Constitution Alignment)

- **程式品質**: 遵循 Controller → Service → Repository 分層，
  TypeScript strict / C# nullable enabled，通過靜態分析。
  資料模型採用 Code First，結構變更透過 EF Core Migrations 管理。
- **測試標準**: Service/Repository 單元測試覆蓋率 ≥ 80%，
  Controller endpoint 含正向與錯誤整合測試，bug fix 附迴歸測試。
- **使用者體驗一致性**: 使用 Element Plus 元件，SCSS + Tailwind CSS
  樣式，顯示載入狀態與使用者友善錯誤訊息。
- **效能需求**: API p95 ≤ 200ms (CRUD) / 500ms (複雜查詢)，
  LCP ≤ 2.5s，初始 bundle ≤ 300KB gzip，無 N+1 查詢。

## Assumptions

- 現有功能（登入、社群登入、電子郵件驗證、選單動態載入）行為完全不變，僅調整視覺樣式
- 配色方案以 vue3-element-admin 預設主題為準（深藍黑側邊欄 #304156、深色登入背景 #2d3a4b）
- 系統 Logo 使用現有「圖書館系統」文字或簡稱；若未來有圖形 Logo 可替換
- 麵包屑導覽資料來源為現有 vue-router 的 route meta 設定
- 側邊欄展開寬度 210px、收合寬度 54px 為預設值，與 vue3-element-admin 一致
- 深色模式（dark mode）不在此次範圍，未來可擴充

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 登入頁面在桌面瀏覽器載入後，視覺樣式與 vue3-element-admin 登入頁一致率達 90% 以上（由人工比對確認）
- **SC-002**: 側邊欄收合/展開動畫流暢，過渡時間在 0.3 秒以內完成，無明顯卡頓或閃爍
- **SC-003**: 使用者首次進入主佈局後，能在 3 秒內辨識並使用側邊欄導覽至目標頁面
- **SC-004**: 行動裝置上（< 768px），側邊欄覆蓋式展開與遮罩收合操作回應時間 < 0.5 秒
- **SC-005**: 所有現有功能（登入、導覽、登出、社群登入）在樣式更新後仍 100% 正常運作，無功能迴歸
- **SC-006**: 頁面初次載入效能（LCP）不因樣式調整而超過 2.5 秒
